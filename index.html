Projects

flagship

SAAHAS — Autonomous UAV Docking & Recovery

Full autonomous precision-landing stack for a drone recovering onto a moving platform. Blends RTK GNSS with OpenCV visual tracking, switching from GPS to a PD-controlled camera lock as the drone descends — with platform-velocity compensation from GPS deltas and a 3-layer noise filter to reject spurious jumps. Also includes an ESP32 head-tracking firmware (MPU6500 sensor fusion + complementary filtering) driving SBUS packets for low-latency FPV gimbal control.

State transitions gated on live thresholds — GPS_FOLLOW → GPS_DESCEND at dist < 0.6m, → CAMERA_LAND at alt < 7m, → LAND only once tracked-area ≥ 80% and pixel error < 15px on both axes.

firmware

Interrupt-Driven UART Driver

Register-level STM32 UART driver in Embedded C — no HAL. Configures UART/GPIO through memory-mapped registers, computes baud-rate timing by hand, and handles RX interrupts via the NVIC.

Non-blocking circular-buffer RX/TX — write ptr advances only inside the ISR, read ptr only in application code. Overflow and UART overrun both flagged explicitly rather than silently dropped.

FreeRTOS UART Activity Monitor

Three concurrent tasks coordinated with binary semaphores and one-shot software timers — no polling.

The timer resets on every RX event; if it ever fires uninterrupted, the system is idle — detected without a single polling loop.
